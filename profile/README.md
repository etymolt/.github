### What we do

Etymolt verifies whether a brand name is safe to use across:

- **Trademark** — 30M+ records across USPTO, EUIPO, UKIPO, JPO, KIPO, CNIPA, CIPO + Madrid Protocol
- **Domain** — RDAP + WhoisXML across 1500+ TLDs
- **Social handles** — GitHub, Twitter/X, Instagram, Threads, TikTok, LinkedIn, Reddit, Mastodon, Bluesky, Farcaster
- **Cultural** — 20-market linguistic + sound-symbolism screen
- **AI-search** — embedding-based phonetic similarity (Voyage + pgvector)
- **News + media** — MediaStack + NewsData common-law collision check
- **TTAB** — 60K+ Trademark Trial and Appeal Board proceedings
